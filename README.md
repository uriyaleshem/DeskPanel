# DeskPanel למחשב Windows

תוכנת המחשב שמחברת את לוח DeskPanel ליומן Google ולמשימות Microsoft To Do.

### [הורדת DeskPanel ל־Windows x64](https://github.com/uriyaleshem/DeskPanel/releases/latest/download/DeskPanel-Windows-x64.zip)

### [מדריך התקנה וחיבור חשבונות בעברית - PDF](https://github.com/uriyaleshem/DeskPanel/releases/latest/download/DeskPanel-Setup-HE.pdf)

[מדריך HTML לפתיחה בדפדפן](https://github.com/uriyaleshem/DeskPanel/releases/latest/download/DeskPanel-Setup-HE.html) · [כל קובצי הגרסה](https://github.com/uriyaleshem/DeskPanel/releases/latest)

## התקנה

1. הורידו את חבילת Windows וחלצו אותה במלואה.
2. השאירו את `DeskPanel.exe` ואת תיקיית `_internal` יחד בתוך תיקיית `DeskPanel`.
3. חברו את הלוח בכבל USB נתונים והפעילו את `DeskPanel.exe`.
4. פתחו הגדרות → חשבונות, וחברו את Google Calendar ואת Microsoft To Do לפי המדריך.

נדרש Windows 10/11 x64. אין צורך בהתקנת Python. לוח שכבר נצרב בגרסה הנוכחית אינו דורש צריבה נוספת בעת מעבר למחשב אחר.

Google דורש קובץ OAuth של Desktop app. Microsoft דורש Application (client) ID ורישום Desktop מתאים, ללא Client Secret. אפשר להשתמש באותם רישומי אפליקציה במחשב נוסף, בהתאם לקהל שהוגדר; בכל מחשב מתחברים לחשבונות מחדש.

הורדת התוכנה ציבורית ואינה דורשת חשבון GitHub. חבילת התוכנה אינה מכילה פרטי חשבונות, אסימוני כניסה או נתוני יומן ומשימות. החשבונות מוגדרים מקומית במחשב המשתמש. התוכנה צריכה להמשיך לפעול לצורך סנכרון הלוח.
