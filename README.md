## התקנה ראשונה או מעבר מגרסה ישנה

1. יוצאים מהתוכנה הישנה דרך הסמל ליד השעון → יציאה.
2. מורידים ומחלצים את כל תיקיית `DeskPanel` למיקום שניתן לכתוב אליו.
3. משאירים את `DeskPanel.exe` ואת תיקיית `_internal` יחד.
4. מחברים את הלוח ב־USB ומפעילים `DeskPanel.exe`.
5. במחשב חדש מחברים חשבונות דרך הגדרות → חשבונות. באותו משתמש Windows החיבורים הקיימים נשמרים.

נדרש Windows 10/11 x64. אין צורך בהתקנת Python. מסך שכבר מריץ DeskPanel אינו זקוק לצריבה נוספת כדי להפעיל את מנגנון העדכונים.

## עדכונים מהמחשב שאליו המסך מחובר

החל מגרסה 1.1.0, הגדרות → **עדכונים** מציגות בנפרד עדכונים לתוכנת המחשב ולמסך. אפשר לבחור הורדה בלבד, התקנת תוכנה או הורדה וצריבה למסך. הבדיקה ברקע מתבצעת כל 15 דקות וניתנת לכיבוי. אין התקנה כפויה.

קוד גישה יכול לפתוח עדכון פרטי, עם הגבלה למחשב מסוים, מספר מחשבים ותוקף. הזנת הקוד אינה מתקינה את העדכון. קבצים פרטיים מוצפנים לפני העלאה, והעדכונים מאומתים באמצעות חתימה ומזהי תוכן.

יש להחליף פעם אחת את תוכנת המחשב הישנה כדי לקבל מנגנון זה. בהמשך ניתן לעדכן דרך התוכנה בלי להביא את המסך למחשב המפתח.

## מידע ופרטיות

ההגדרות נשמרות ב־`%LOCALAPPDATA%\DeskPanel`. החבילה אינה כוללת פרטי חשבונות, אסימונים או נתוני יומן ומשימות. התוכנה צריכה להמשיך לפעול לסנכרון הלוח.

דיווח למנהל כולל רק מזהה התקנה, שם נבחר, גרסאות ומצב עדכון; ניתן לכבות אותו בהגדרות. הספירה היא של התקנות מחשב מדווחות, לא של אנשים. תוכן היומן והמשימות ומפתחות החשבונות אינם נשלחים לשרת העדכונים.

Google דורש קובץ OAuth של Desktop app. Microsoft דורש Application (client) ID ורישום Desktop מתאים, ללא Client Secret. במחשב חדש מתחברים לחשבונות מחדש.
