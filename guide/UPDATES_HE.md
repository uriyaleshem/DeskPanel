# DeskPanel — עדכונים וניהול

הורדת תוכנת המחשב: https://screen.classifyapp.org

## מעבר חד־פעמי מהמחשבים הקיימים

1. יוצאים מ־DeskPanel דרך הסמל ליד השעון → יציאה.
2. מורידים את קובץ ה־ZIP החדש ומחלצים את **כל תיקיית DeskPanel**, כולל `_internal`, לתיקייה רגילה שאפשר לכתוב אליה, למשל Documents או `%LOCALAPPDATA%\Programs`.
3. מפעילים את `DeskPanel.exe` מהתיקייה החדשה. ההגדרות והחיבורים הקיימים נטענים אוטומטית מאותו משתמש Windows.
4. מחברים את המסך ב־USB כפי שהיה עד היום. **לא נדרשת צריבה ראשונית נוספת למסך שכבר מריץ DeskPanel**.

גרסאות המחשב הישנות אינן מכילות מנגנון עדכונים, ולכן את ההחלפה הזאת צריך לעשות פעם אחת בכל מחשב. לאחר מכן אין צורך להביא את המסך למחשב המפתח.

## שימוש בעדכונים

בהגדרות → **עדכונים**, לוחצים **בדיקת עדכונים**. תוכנת המחשב והמסך מוצגים בנפרד, כולל הגרסה ותיאור השינויים.

- **הורדה בלבד** שומרת קובץ מאומת במחשב, בלי להתקין.
- **הורדה והתקנה** מחליפה את תוכנת המחשב. התוכנה נסגרת ונפתחת מחדש. נדרש מקום פנוי של לפחות 2GB ותיקיית התקנה שניתנת לכתיבה. נשמרת תיקיית גיבוי ליד תיקיית התוכנה; אם הגרסה החדשה אינה עולה, הגרסה הקודמת משוחזרת.
- **הורדה וצריבה למסך** מעדכנת את המסך המחובר לאותו מחשב. משאירים את הכבל ואת החשמל מחוברים עד שמתקבל אישור שהמסך עלה. נכתבת רק מחיצת האפליקציה; הגדרות המסך נשמרות.
- אם צריבה נקטעה, מחברים שוב את אותו מסך ולוחצים **נסה שוב צריבת מסך שנקטעה**. המזהה הפיזי ופריסת הזיכרון נבדקים לפני כתיבה. אם חיבור ה־COM השתנה או פריסת הזיכרון שונה, נדרשת עזרה טכנית; אין מחיקה כללית אוטומטית.

בדיקה ברקע מתבצעת כל 15 דקות וניתנת לכיבוי. **אין התקנות כפויות או אוטומטיות**. אפשר להמשיך לעבוד גם בלי חיבור לשירות העדכונים.

## עדכון באמצעות קוד

מזינים קוד באזור **קיבלת עדכון אישי?** ולוחצים **הפעל קוד**. הקוד פותח גישה; הוא אינו מתקין דבר. אחר כך בוחרים הורדה או התקנה בכרטיס המתאים.

קוד יכול להעניק גישה לעדכון המחשב, למסך או לשניהם. אפשר להגביל אותו למחשב מסוים, למספר מחשבים ולתאריך תפוגה. מזהה המחשב זמין באמצעות **העתק מזהה מחשב**. הגבלת שימושים היא לפי התקנות מחשב שונות, ולא לפי מספר לחיצות או הורדות באותו מחשב.

## תוכנת המנהל

פותחים את `DeskPanelAdmin.exe` מתוך תיקיית `DeskPanelAdmin`, עם תיקיית `_internal` שלה. במחשב הבעלים הנוכחי פרטי הניהול כבר הוגדרו.

### מחשבים

הרשימה מציגה שם שהמשתמש בחר, מזהה התקנה, גרסת תוכנת מחשב, גרסת מסך, זמן בדיקה אחרון ותוצאת עדכון אחרונה. ניתן להעתיק מזהה ולחסום קבלת עדכונים עתידית להתקנה.

המספרים הם **התקנות מחשב מדווחות — לא אנשים**. גרסאות ישנות לא מופיעות עד שמחליפים אותן פעם אחת לגרסה החדשה. הנתונים מתעדכנים כשלקוח מבצע בדיקה, בדרך כלל בתוך 15 דקות. אפשר לכבות דיווח בתוכנת הלקוח; אז פרטי הגרסאות והשם מוסרים מהרשימה. מזהה טכני נשמר לצורך אימות קודים.

### פרסום לכל המחשבים

1. מכינים ובודקים גרסה חדשה. מנגנון העדכון מפיץ תוכנה שנבנתה; הוא אינו משנה בעצמו קוד מקור.
2. בלשונית **הפצות** בוחרים מחשב או מסך, ואת **עדכון זמין לכל המחשבים**.
3. למחשב בוחרים את `DeskPanel-Windows-x64.zip` שנוצר מתהליך הבנייה. הגרסה נקראת מתוך החבילה. **יש להעלות מספר גרסה חדש בכל שינוי**, למשל 1.1.1 אחרי 1.1.0.
4. למסך בוחרים את `deskpanel.bin` מתוך תיקיית הבנייה, ומזינים את `DP_BUILD` המדויק. גם מזהה זה חייב להשתנות בכל גרסת קושחה חדשה. פריסת המחיצות חייבת להישאר תואמת.
5. מוסיפים תיאור ולוחצים **העלה ופרסם עדכון**. רק לאחר שההעלאה ואימות הקובץ הסתיימו, ההפצה נרשמת בשירות.

עדכון למחשב בלבד אינו דורש קושחה חדשה; עדכון למסך בלבד אינו דורש EXE חדש. קישור ההורדה הראשי מתעדכן רק בהפצת מחשב ציבורית.

### פרסום פרטי

1. בלשונית **הפצות**, בוחרים **עדכון פרטי — נדרש קוד**, מעלים את החבילה וממתינים להצלחה.
2. בלשונית **קודי גישה**, מסמנים הפצה פרטית אחת או יותר.
3. בוחרים מחשב מהרשימה, או כל מחשב שמחזיק בקוד; מגדירים מספר מחשבים מרבי ותוקף בימים.
4. לוחצים **צור קוד גישה**, ואז **העתק את הקוד החדש**. השרת אינו שומר את הקוד המלא; יש לשמור אותו בעת היצירה.

הקובץ הפרטי מוצפן לפני ההעלאה ל־GitHub. קישור ציבורי לקובץ המוצפן אינו מספיק כדי להתקינו. ביטול קוד או עצירת הפצה חוסמים גישה חדשה; הם אינם מוחקים קבצים שכבר הורדו ואינם מחזירים לאחור תוכנות שכבר הותקנו.

## גיבוי וניהול ממחשב אחר

בלשונית **גישה והסבר** יש **ייצא גיבוי ניהול מוצפן בסיסמה**. שומרים את קובץ `.dpbackup` וסיסמה של 12 תווים לפחות במקום בטוח. במחשב מנהל אחר מעבירים את כל תיקיית `DeskPanelAdmin` ומייבאים את הגיבוי באמצעות **ייבא גיבוי ניהול מוצפן**.

להעלאת קבצים ל־GitHub נדרש גם חיבור של הבעלים דרך Git Credential Manager, או מפתח GitHub בעל הרשאת Contents לקריאה וכתיבה במאגר `uriyaleshem/DeskPanel`. מפתח כזה ניתן להזנה בלשונית הגישה. במחשב הנוכחי משתמשים בחיבור GitHub הקיים.

## מיקום הקבצים

- הגדרות וחיבורי המשתמש: `%LOCALAPPDATA%\DeskPanel`.
- קבצים שהורדו, תוצאות ולוגי התקנה: `%LOCALAPPDATA%\DeskPanel\updates`.
- פרטי ניהול מוצפנים ב־Windows: `%LOCALAPPDATA%\DeskPanelAdmin`.
- גיבוי הגרסה הקודמת: תיקייה בשם `DeskPanel.backup-...` ליד התוכנה. אפשר למחוק אותה לאחר שווידאת שהגרסה החדשה תקינה; אין למחוק את תיקיית ההגדרות.

מפתחות החשבונות מוגנים באמצעות משתמש Windows. העתקת קובצי `.protected` למשתמש או מחשב אחר אינה דרך להעברת החיבורים; בלקוח מתחברים שוב לחשבונות, ובניהול משתמשים בגיבוי המוצפן.

## גבולות המערכת

השירות מיועד ל־Windows ולמסך Waveshare ESP32-S3-Touch-LCD-7B עם פריסת DeskPanel הנוכחית. צריבה מתבצעת דרך USB במחשב שאליו המסך מחובר. מסך חדש עם תוכנה זרה זקוק לצריבה הראשונית הרגילה. הפסקת חשמל בזמן צריבה עשויה לדרוש ניסיון צריבה חוזר; אין במסך הנוכחי שתי מחיצות קושחה לחזרה אוטומטית.

לשרת לא נשלחים תוכן יומן, משימות, כתובות דוא״ל או מפתחות החיבור לחשבונות.
